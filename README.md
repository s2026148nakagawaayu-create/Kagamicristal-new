# KAGAMI CRYSTAL — bilingual concept website

A responsive Japanese/English concept website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — Japanese version
- `en/index.html` — English version (adapted for an international audience)
- `style.css` — shared responsive design and animations
- `script.js` — hamburger menu and scroll-reveal animation

## Run locally
Open the folder in VS Code. For a local preview, use the VS Code Live Server extension, or open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a GitHub repository and upload all files while preserving the `en` folder.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then click **Save**.
5. Wait for the deployment to finish. The URL will be shown in **Settings → Pages**.
6. Open the published URL and test both `JP` and `EN` links.

If the repository is named `username.github.io`, the site is usually at `https://username.github.io/`. For a project repository, it is usually at `https://username.github.io/repository-name/`.

## Notes
- This is an independent concept project inspired by Kagami Crystal, not an official website and not affiliated with the company.
- The crystal product illustrations are made with CSS and are not photographs or depictions of specific products.
- If you add real product photos, logos, product names, or official text, check permissions and use accurate source material.
- Google Fonts is loaded from an external service; the site still has fallback fonts if it cannot load.
